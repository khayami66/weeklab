## 本書の目的
本書は、Weeklab（小学校教員向け週案作成支援Webアプリ）の実装作業を**フェーズごとにチェックボックス化**し、進捗を可視化するための手順書です。各項目を完了するたびにチェックを入れ、フェーズ単位での完了確認ができます。

## 凡例
- `- [ ]` … 未完了
- `- [x]` … 完了
- 太字の見出しは**フェーズ完了条件**（すべて満たしたら次フェーズへ）
- **フェーズ番号順に進むとは限らない。**実務の都合で順序を入れ替えた場合は、その理由を該当フェーズの冒頭に書く
  （例：成績処理 G1〜G4 は成績時期のため Phase 13 より優先、Phase 17 は移行入力の前提として Phase 15/16 より先に実施）

## Phase G1〜G4: 成績処理層（2026-09-01 追加）

**割り込みの理由**：9月＝成績処理の時期に入り、「週案と成績を1つのアプリで完結させたい」との
要望があったため、Phase 13（週案印刷）より優先した。
